# 每日清单 DailyList

一个简单好用的 Windows / macOS 桌面待办小工具，帮你记住每天要做的事。基于 Electron 开发，支持系统托盘常驻、置顶悬浮窗、到点系统通知提醒，数据纯本地存储，无需联网、无需登录。

## 功能特性

- **今日清单**：打开即见“今天要做的事”，按优先级自动排序，做完打勾
- **任务搜索**：`Ctrl+F` 全局搜索，跨日期匹配标题/备注/分类，结果按日期排列并显示归属
- **优先级 / 分类 / 时间**：高、中、低三档优先级（色条 + 标签展示），自定义分类，可为任务设定具体时间
- **提前量提醒**：每个任务可选 不提醒 / 到点 / 提前 5、10、15、30、60 分钟，到时弹出系统通知；睡眠唤醒后自动补发错过的提醒
- **重复任务**：支持“每天 / 每周”重复，完成一次自动生成下一次实例，未完成的跨天自动滚动到今天
- **系统托盘常驻**：关闭窗口自动缩到托盘，托盘图标悬停显示“今天还有 N 件未完成”，右键可快速开关悬浮窗或退出
- **置顶悬浮窗**：深色半透明小窗始终显示今日未完成任务，可随意拖动（位置自动记忆），随时开启或关闭
- **归档与统计**：完成的任务收进“已完成”区可回看，头部实时显示“本周已完成 N 件”，并附近 7 天完成趋势小图
- **开机自启**：设置内一键开关，无需手动配置启动文件夹
- **数据导出 / 导入**：一键备份全部数据为 JSON 文件，换机迁移、跨设备搬家都方便
- **自动清理**：可设置自动清理 N 天前已完成的任务，历史数据不再无限膨胀
- **深色模式**：自动跟随系统深浅色偏好
- **本地存储 + 自动备份**：数据保存在本机 JSON 文件，每次保存前自动生成备份，不怕丢数据

## 快速开始

### 方式一：直接下载使用

在 [Releases](../../releases) 页面根据系统选择下载：

| 文件 | 说明 |
| --- | --- |
| `DailyList.Setup.x.x.x.exe` | Windows 安装版，自动创建桌面快捷方式（推荐日常使用） |
| `DailyList.x.x.x.exe` | Windows 便携版，单文件免安装，双击即用，适合放 U 盘 |
| `DailyList-1.2.0-arm64.dmg` | macOS Apple Silicon 安装包 |
| `DailyList-1.2.0-arm64-mac.zip` | macOS Apple Silicon 免安装压缩包 |

### 方式二：从源码运行

环境要求：Node.js 22+

```bash
# 克隆仓库
git clone https://github.com/Sudoooo98s/TodoList.git
cd TodoList

# 安装依赖（国内网络建议配置 electron 镜像）
# PowerShell: $env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install

# 启动开发版
npm start

# 运行轻量自验证
npm test

# 运行 GUI 冒烟自验证
npm run test:gui
```

## 使用说明

### 任务搜索

- 快捷键 `Ctrl+F` 聚焦搜索框，输入即搜，匹配范围包含任务标题、备注与分类
- 搜索结果跨日期显示（每条附日期标签），按日期从早到晚排列；`Esc` 清空并退出搜索
- 切换日期时会自动退出搜索，回到对应日期的单日清单

### 添加任务

1. 在顶部输入框直接输入任务，回车即可快速添加（快捷键 `Ctrl+N` 可随时聚焦输入框，`Esc` 关闭设置弹窗）
2. 点击“详细”可展开完整设置：日期、时间、提醒提前量、重复、优先级、分类、备注（未设定时间时“提醒”选项自动禁用）

### 重复任务

- 详细设置中可将任务设为“每天”或“每周”重复
- 完成后会自动生成下一次实例（按重复规则、标题、日期、时间和分类去重）
- 取消完成时会删除该任务自动生成且尚未完成的下一次实例，不会影响手工创建或已完成的实例
- 当天没做完的重复任务，跨天后自动滚动到今天

### 数据导入 / 导出

- 设置 → 数据 → 「导出数据」可将全部任务与设置备份为 JSON 文件
- 「导入数据」从备份文件恢复，导入前会确认（覆盖当前数据）

### 删除与撤销

- 删除任务后底部会弹出提示条，6 秒内点「撤销」可恢复

### 任务提醒

- 给任务设定时间后，选择“提前 N 分钟提醒”，到点会弹出系统通知
- 点击通知可直接打开主窗口
- 提醒生效的前提是程序在运行——最小化到托盘即可，不需要窗口一直开着

### 日期导航

- 点击「‹ ›」翻看前一天 / 后一天的任务
- 点击「今天」随时回到今日清单

### 悬浮窗

- 顶栏「悬浮窗」按钮或托盘右键菜单可开关
- 悬浮窗置顶显示今日未完成任务，可拖动到屏幕任意位置，位置会自动记住
- 点悬浮窗右上角 × 关闭（等同关闭开关，不会退出程序）

### macOS 集成

- 仅提供 Apple Silicon 安装包
- 点击 Dock 图标会重新显示主窗口
- 菜单栏保留标准应用菜单，支持复制、粘贴、全选、隐藏与退出
- 菜单栏图标使用 16x16 Template 图标，自动适配浅色/深色菜单栏

### 数据存储

- Windows 数据文件：`%APPDATA%\每日清单\todo-data.json`
- macOS 数据文件：`~/Library/Application Support/每日清单/todo-data.json`
- 自动备份：每次保存前生成 `todo-data.backup.json`
- 主数据文件损坏时会自动尝试从备份恢复

## 常见问题

**Q: 提醒没有弹出？**
A: 请确认程序在运行（托盘里有图标），且系统设置中允许了应用通知。设置页可点「发送测试通知」验证。

**Q: macOS 提示应用无法验证？**
A: 当前发布包未做开发者签名与公证。首次打开时可右键点击应用选择「打开」，或在「系统设置 → 隐私与安全性」中允许运行。

**Q: 怎么让软件开机自启？**
A: 设置 → 常规 → 打开「开机自动启动」即可。

**Q: 数据能同步到其他设备吗？**
A: 通过「导出数据」生成 JSON 备份文件，复制到其他设备后用「导入数据」恢复；也可手动复制 `%APPDATA%\每日清单\` 下的数据文件。
